# Ultramarine KDE Theme

This repo holds the default theme for Ultramarine Plasma.

For each release, merge from the upstream plasma-lookandfeel-fedora package (https://src.fedoraproject.org/rpms/plasma-workspace).

## SOP

If a new default background is added, *always* update this package to reflect the changes. You can find the upstream theme files after installing the plasma-lookandfeel-fedora package, at `/usr/share/plasma/look-and-feel/org.fedoraproject.fedora.desktop`/.
